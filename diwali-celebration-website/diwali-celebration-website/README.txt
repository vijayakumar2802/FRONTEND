DIWALI GLOW — FESTIVAL OF LIGHTS WEBSITE

PROJECT FILES
- index.html  : Website structure and all sections
- style.css   : Premium dark purple and gold design, responsive layout and animations
- script.js   : Mobile menu, diya surprise effect, sparkle animation and wish button

HOW TO RUN
1. Extract the ZIP file.
2. Open the diwali-celebration-website folder in VS Code.
3. Open index.html in your browser, or use the Live Server extension.
4. Internet is needed only to load the Google Fonts. The website itself works without a backend.

CUSTOMIZE
- Edit the sample activities and text directly in index.html.
- Replace the sample gallery cards with your own photos.
- Change colours in the :root section at the top of style.css.

This is a front-end static website. It does not require npm, React, a database or a server.
